# AI资源工坊 · 汇报演示指令卡（6 类型）

本地启动：双击 START-Mac.command（Mac）或 START-Windows.bat（Windows）→ 浏览器自动打开 http://localhost:3000
入口：左侧「AI备课」→ 首页

## 1. 教学动画 —— 光合作用

- 类型 chip：点 `教学动画`
- 输入：`给我生出一份光合作用课件`
- 流程：准备教学动画 → 设计视觉方案 → 准备任务选项 → **信息确认表单**（已预选）→ 确认 → 确定动画方案 → 制作教学动画 → 修复页面标记 → 修复公式加载 → 修复公式显示 → 修复移动端适配 → 修复窄屏布局 → 完成最终验收 → 发布教学动画
- 右侧演示点：分栏滑入后，点课件里的 **「播放动画」** 自动演示 6 步光合作用；切 **「有光/无光」** 看产物变化；点右侧步骤卡跳转

## 2. 互动课件 —— 勾股定理探究

- 类型 chip：点 `互动课件`
- 输入：`设计初中数学勾股定理互动教学活动，引导学生主动探究，培养几何直观、逻辑推理能力。`
- 流程：记录教学目标 → 准备视觉方案 → 准备页面制作 → 检索数学可视化 → **信息确认表单** → 创建探究动画 → 修复拖拽卡片 → 修复卡片点击 → 发布勾股定理探究动画
- 右侧演示点：**拖拽三块正方形对齐到三角形边上**看面积关系；点“面积测量 / 即时反馈练习”交互
- 备用（同类型第二案例）：输入 `生成人生天数计算互动课件` → 右侧《人生有几万天》拖年龄/寿命滑块、按年看/按天看切换

## 3. AI组题 —— 七年级数学试卷

- 类型 chip：点 `AI组题`
- 输入：`帮我出一份数学试卷`
- 流程：**信息确认表单**（学段默认已选 `初中`）→ 确认 → 搜索试卷（列表）→ 过往考情分析 → 题目检索结果卡 → 生成有理数单元测试卷
- 右侧演示点：**依次点击试卷列表前 3 条**（平谷区第七/第五/第六单元卷），左侧稳定停在列表处不跳动，只有右侧预览切换对应试卷；预览顶部 **题目导航 1–23** 点题号直达对应题

## 4. AI命题 —— 图片出题

- 类型 chip：点 `AI命题`
- 操作：点输入框左侧 **`+` → 上传文件**，任选一张图片；输入：`根据这张图片出几道同步练习题`
- 流程：加载命题能力 → 识别图片素材（图片显示在你的消息里）→ **信息确认表单**（图片用途/学科/学段/命题要求）→ 任务规划 SOP 清单卡 → 检索知识点标准名 → **研读课程标准卡（可点「展开」）** → **题目检索结果卡（题目总数 27）** → 生成同步练习题单
- 右侧演示点：真实题单全文（基础计算 + 行程应用，公式完整），可 查看/下载 docx

## 5. 教育应用 —— 古文沉浸式漫游《桃花源记》

- 类型 chip：点 `教育应用`
- 输入：`改编《古文沉浸式漫游《桃花源记》》`
- 流程：解析原应用 → 读取应用入口 → 分析叙事结构 → 复用热点探索交互 → 走查样式骨架 → 改编应用界面 → 替换媒体资源 → 部署应用 → 部署完成（独立访问链接已生成）
- 右侧演示点：真实已部署应用本体——桃花画卷封面点 **「开始探索」**，六章古文画卷逐章漫游、点场景热点看原文解读

## 6. 教学游戏 —— 西游取经·古诗词闯关（新增）

- 类型 chip：点 `教学游戏`（输入框提示语已预置本条指令，可直接回车）
- 输入：`以《西游记》取经之路为故事线，生成六年级课内古诗词闯关游戏，每关设诗词情景题，答对方能解锁下一段取经剧情。`
- 流程：记录游戏目标 → 读取闯关设计规范 → 生成视觉方案 → 检索语文课件经验 → 读取主题索引 → 准备确认选项 → **信息确认表单（5 题：教材范围 / 关卡数 / 游戏能力 / 视觉风格 / 其他需求）** → 锁定游戏方案 → 读取纸本主题 → 加载网页制作规范 → **生成取经插图（图片生成卡）** → 整理游戏素材 → 成品卡「制作闯关游戏」→ 记录修复进度 → 读取待修复代码 → 加载验收规范 → 成品卡「修复游戏代码」→ 验收闯关闭环 → 检查图片资源 → 复测游戏交互 → 发布闯关游戏 → 完成游戏交付
- 右侧演示点：怀旧纸本棕长卷开场页 → 点 **「开始取经」**，五段剧情逐关解锁；每关三道诗词情景题（诗句选择 / 名句填空 / 诗句与情境配对），答错停留当前关并给解析；顶部实时显示 **关卡 / 得分 / 连击**，可用 **提示卡** 排除干扰项；通关后出总得分、正确率与最高连击

## 本版界面变化（演示时可顺带说明）

- 工坊自己的左侧导航栏已取消：任务记录改为**右上角悬浮「任务记录」抽屉**（240px，点开覆盖在内容上，选任务或点空白自动收起；有任务在跑时入口带红色数字角标）
- 平台左导航的折叠按钮**悬浮在内容区左上角**，展开/收起时位置不变
- 聊天页顶部有 **‹ 首页 / 作品名** 面包屑，任何一步都能回首页
- 首页右上角新增两个入口：**AI资源数据看板**（KPI + 区域使用趋势 + 高频 AI 能力榜 + 校本 AI 增长飞轮 + 实时动态）、**AI知识图谱**（力导向节点图，可拖拽缩放、搜索、按 Wiki/文件夹切换视图）
- 教学资源、教学应用、我的资源三个 tab 里的卡片**全部是本校老师自己生成的作品**（共 10 张，封面为成品实拍截图，作者显示「我」）；命题与组卷的封面是真实试卷页截图，飞象原站的示例卡片已全部移除
- 广场列表新增 **年级筛选**（全部 / 一年级～九年级），教学资源与教学应用两个页面都有
- 任务记录每条**鼠标悬浮出现删除图标**，可单条删除；删除仅本次会话有效，刷新即恢复，列表下方有「恢复已删除的 N 条」

## 演示小贴士

- 表单弹出后页面会停在表单开头，**手动滑到底点「确认」**（和真实产品节奏一致）；不点也有 1:04 自动跳过倒计时
- 中途想停止：输入框右侧红色 **停止键**
- 临时任务跑完即从任务记录收起，不会留杂项；随便输入的非案例描述也不会残留
- 每个案例右侧预览出现时是**分割线左滑**展开，可稍作停顿再操作，观感更接近真实产品
- 全部内容（动画 / 课件 / 游戏 / 试卷 / 视频 / 字体）均已内置，**完全离线可演示，无需联网**
- 作品详情页与聊天预览均走本地成品，不请求任何外部域名
