AI资源工坊 · 汇报演示包（最终版）

【环境要求】
电脑装好 Node.js（18 及以上，建议 20/22）。没装的话去 nodejs.org 下载安装，一路下一步即可。

【怎么启动】
Mac：双击 START-Mac.command（若提示无法打开，右键→打开一次即可）
Windows：双击 START-Windows.bat
浏览器会自动打开 http://localhost:3000

【演示入口】
工作台 → AI资源工坊 首页。五个案例的输入指令见《演示指令卡.txt》。

【注意】
- 全部内容（含光合作用、桃花源记、唐诗图谱的动画/视频/字体）均已内置，完全离线可演示，无需联网。
